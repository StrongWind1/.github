# .github

Default community health files for [StrongWind1](https://github.com/StrongWind1) repositories. GitHub uses each file here for any repository that does not ship its own copy.

| File | Purpose |
| --- | --- |
| [SECURITY.md](SECURITY.md) | How to report a vulnerability privately |
| [SUPPORT.md](SUPPORT.md) | Where to find documentation and get help |
| [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/) | Bug report and feature request templates |
| [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) | Pull request checklist |

Issue templates are all-or-nothing: a repository with its own `.github/ISSUE_TEMPLATE/` directory uses only its own templates, never these.
