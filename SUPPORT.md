# Support

This is the default support policy for every [StrongWind1](https://github.com/StrongWind1) repository that does not ship its own.

## Documentation

Start with the repository's README. Most projects also publish full documentation under [strongwind.dev](https://strongwind.dev/), which lists every tool.

## Bugs and feature requests

Open an issue on the affected repository using the bug report or feature request template. For bugs, include the exact command you ran, the full output, and the version you are running.

## Security issues

Do not open a public issue. Follow the [security policy](https://github.com/StrongWind1/.github/blob/main/SECURITY.md).

## Everything else

For questions that do not fit an issue, email [hello@strongwind.dev](mailto:hello@strongwind.dev). Support is best effort.
